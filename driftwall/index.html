Driftwall

A wallpaper switcher for Windows. Photos from the web and your own folders, on a schedule you choose, on every monitor at its native resolution. It sits in the notification area doing nothing between changes, and gets out of the way while you game.

Download for Windows Source code

Free · MIT licence · Windows 10 and 11, 64-bit · no account needed

What it does

Photos from anywhere, on your terms

Ten sources, mixed

Wallhaven, Bing's daily photo, Unsplash, Pexels, Pixabay, Flickr, Reddit, NASA's Astronomy Picture of the Day, any RSS or Atom feed, and folders on your PC. Each gets a weight.

Top, category or search

Per source. Run "Wallhaven top of the month" next to "Unsplash search: brutalist architecture".

Real multi-monitor

Every display gets its own photo rendered at its exact pixel size. A 4K screen is never fed a 1080p file, and portrait displays get portrait photos. Mixed DPI just works.

On your schedule

Any interval from five minutes to a day, plus optional changes at sign-in, on unlock, and at shutdown so the next sign-in is already new.

Browse and keep

Look through everything a source offers inside the app, save what you like into collections, then use a collection as a source of its own. Saved photos work offline.

Five ways to fit

Fill, Fit, Stretch, Center, Tile. Fit fills the empty area with a blurred copy of the photo, a flat colour, or the photo's own average colour. Changes apply as you make them.

Screens

Built to be closed

You will see this window when you set things up, and rarely after. The rest of the time Driftwall is an icon next to the clock.

Staying out of the way

The resource behaviour was the design constraint

  • No polling. One timer, armed once per change. Between changes the app does nothing at all: about 35 MB resident and zero CPU.
  • Pauses for games. Fullscreen apps, presentations and exclusive Direct3D are detected when the timer fires and the change waits. Optional pauses for battery and metered connections.
  • Decodes only what it needs. A 45-megapixel photo bound for a 1080p monitor is decoded at about 2 megapixels. Full-size decoding never happens.
  • Gives memory back. Closing the window compacts the heap and returns the working set to Windows.
  • No GPU use. Composition runs in software on a low-priority thread, so it never competes with a game.

Install

Two ways in

Installer

Download DriftwallSetup-1.0.0.exe from the latest release and run it. It installs for your user only, no administrator prompt, adds a Start menu entry and, if you like, starts Driftwall quietly when you sign in. Uninstall from Settings › Apps; your collections stay unless you say otherwise.

Portable

Download Driftwall.exe on its own and put it anywhere. It is self-contained, needs no .NET runtime installed, and keeps its settings in %LOCALAPPDATA%\Driftwall.

Windows may say "Unknown publisher". Releases are not yet code-signed, so SmartScreen shows a warning the first time. Choose More info, then Run anyway. Every release lists SHA-256 checksums so you can verify what you downloaded, and the source is public if you would rather build it yourself.

Questions

Short answers

Does it need an account or send anything anywhere?

No account. The only network traffic is fetching photos from the sources you enabled, plus the attribution ping some providers require when a photo is used.

Will it slow down my games?

No. Changes are deferred while a fullscreen app is running, and the app uses no GPU at all for its own rendering.

Can I use a photo I like as my permanent wallpaper?

Yes. Pause the rotation from the tray menu, or save the photo to a collection so it survives cache clean-ups and works offline.

What about the licences of the photos?

They vary by source. Every photo links to its source page, which is the authoritative word on what you may do with it. The repository's SOURCES.md summarises each provider's terms.

Keyboard shortcuts?

Ctrl + → next, Ctrl + ← previous, F5 re-render, Esc close to the notification area.
